PROJECT [04]

The data warehouse documented from scratch — from reverse-engineering to source of truth

The existing documentation mentioned 4 schemas. Exploration revealed 24, across 3 databases. This project reconstructed the real lineage of ~65 views and produced the technical reference that now serves as context for the MCP POC.

ARCHITECTURE : EXPLORATION → LINEAGE → REFERENCE

WHY IT MATTERS

Mapping as an asset, not a chore

finding_01

The declared was not the real

Four documented schemas, twenty-four in production: that gap wasn't a detail, it was the teams' daily life — every question about an unknown view escalated to the same person. The reference broke that dependency on individual knowledge.

finding_02

A reference that serves twice

Written first for humans, the reference became the structured context of the MCP POC: the 24 schemas and the view lineage are exactly what an LLM needs to query the warehouse without hallucinating tables.
