    LA DÉMARCHE

    Pourquoi deux dashboards et pas un

    audience_01, c-level

    Une lecture, pas une exploration

    Cinq chiffres, une tendance, une répartition, une phrase. Aucun filtre : si le lecteur doit manipuler l'outil pour comprendre, le design a échoué. La variation vs mois précédent porte le message ; le détail se demande en réunion, pas dans le dashboard.

    audience_02, opérations

    Actionnable avant d'être joli

    Les équipes vivent dans cet écran : filtres croisés, tableau triable, alertes du jour en tête. La densité est un choix assumé — ce qui compte, c'est que la ligne à traiter en premier soit visible en premier. Même donnée, hiérarchie inversée.
