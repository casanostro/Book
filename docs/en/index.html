05Beliefs

Five things I hold to be true

01
Bad data is not a technical detail. A false, reassuring metric costs more than a true, uncomfortable one. A system's silence is often the real bug.
02
Automating a bad process only speeds up the problem. 159 automations does not mean 159 reliable ones. The question is not how many, but which ones hold in production.
03
A dashboard is not a product. Designing a dashboard is an audience decision before it is a chart decision. The single dashboard "for everyone" is the classic mistake.
04
Documentation is infrastructure. A system only I understand is a failure, not an achievement. Written once, a good map serves humans and models alike.
05
A useful prototype beats a perfect backlog never shipped. AI does not replace business judgment; it augments it, provided you set guardrails, evaluate, and keep a human in the loop.
